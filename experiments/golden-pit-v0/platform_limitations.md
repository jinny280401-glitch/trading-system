# Platform Limitations v0.2

**日期**: 2026-07-22 | **版本**: v0.2 (FROZEN)

## 1. 系统边界

| 系统 | 能力 | 用途 |
|------|------|------|
| `jqdatasdk` (本地 Python SDK) | 仅数据查询 | 不可用于本实验 |
| joinquant.com 策略环境 (`from jqdata import *`) | 回测 + 模拟交易 | **本实验唯一执行环境** |

**关键**：`jqdatasdk` 不含 `order()`/`run_daily()`/回测引擎。策略代码必须粘贴到聚宽网页编辑器运行。本地 `jqdata_query` MCP 工具是数据层，不是执行层。

## 2. 数据限制

| 限制 | 影响 | 处理 |
|------|------|------|
| 日线 `get_price` 不含当日 | 盘中策略不可查今日日线 | 信号用 T-1 或 after_close 数据 |
| 分钟 `get_price` ≤ 30 交易日/次 | 长区间需分批 | 非阻塞（回测数据由引擎管理） |
| 分钟 bar 时间标签语义待确认 | 09:30 bar 是 09:30 开始还是结束 | 待 Smoke #2 验证 |

## 3. 已知偏差

| 偏差 | 说明 | 标注 |
|------|------|------|
| M6 市场环境 | 使用 T-1 CSI 300 数据，非 10:00 实时 | `DEGRADED` |
| M4 量比 | 精确历史分钟量不可用，已移除 | `REMOVED` |
| 滑点模型 | 参数待 Smoke 确认 | `PENDING SMOKE` |
| 历史成分股 | `get_index_stocks(date=...)` 需逐日验证 | `BLOCKING GATE` |
| 最低佣金 5 元 | 本地回测无此限制，聚宽有 | 已纳入成本模型 |

## 4. 与本地回测器的关键差异

| 差异 | 本地 (`trading-system/`) | 聚宽 |
|------|--------------------------|------|
| 佣金最低 | 无 | 5 元 |
| 印花税 | 0.05% | 0.05% |
| 停牌处理 | 跳过 | `paused` 字段 |
| 涨跌停 | 跳过 | `high_limit`/`low_limit` |
| 滑点 | 0.1% 比例 | 待 Smoke |
| 数据源 | Baostock + AkShare | 聚宽内置 |

## 5. Blocking Gates

| Gate | 条件 | 未通过时 |
|------|------|---------|
| 历史成分股重建 | 3 个日期验证通过 | 实验停止 |
| 分钟 bar 闭合语义 | Smoke 确认时间戳 | 调整判定时间 |
| 滑点模型 | Smoke 确认参数 | 使用保守估计 |
